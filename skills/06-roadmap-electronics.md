# Roadmap to seed: Electronics & Embedded Systems

This is the first roadmap to load into the system via the admin
CRUD/seed process (see `03-admin.md`). It's the user's own
"Electronics & Embedded Systems Roadmap — 2026" document, restructured
into the roadmap template. Category tags (`theory` / `practical`) are
inferred from whether the item is conceptual understanding vs. hands-on
building — treat these as a reasonable starting point, not a rigid rule;
the user can recategorize via the admin UI if a tag doesn't fit.

- **Roadmap name:** Electronics & Embedded Systems
- **Suggested color:** green
- **Description:** From absolute beginner in electronics to designing,
  programming, debugging, and building real-world embedded systems.
